# my_adhan

This python script webscrapes the current prayer times from www.namaztakvimi.com and and plays a mp3 file if it is time for prayer. The script checks the prayer time every minute.
Edit the variable LINK for your specific city.
You can comment in/out the prayer times you want to hear with the time_to_check variable.
Updating the time should be done by killing and restarting the process at 00:00 with cronjob.
